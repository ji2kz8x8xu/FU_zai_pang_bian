# FuZaiPangBian (Desktop AI Assistant)

**FuZaiPangBian** is a desktop floating assistant built with **Python (PyQt6)**. It features a satisfying **"Jelly Physics"** engine and integrates **Google Gemini AI** to provide a seamless, interactive chat experience right on your desktop.

## Key Features

* **Smart Snapping**: The ball automatically snaps to the nearest screen edge with natural inertia.
* **Gemini AI Integration**: Chat with Google's Gemini 2.0 Flash model directly from the floating panel.
* **Voice Input**: Support for speech-to-text input for hands-free interaction.
* **Intelligent UI**: The chat window automatically positions itself to avoid screen edges and the taskbar.
* **Auto-Collapse**: The ball automatically shrinks into a small tab when idle to save screen space.
